# Gate 2 — selective consolidation under sequential interference

Design written locally before the 8-seed run on 2026-10-29, but not externally timestamped or publicly preregistered before results. No tuning on the eight selected seeds; report a negative if stronger controls tie. Scientific scope: synthetic NumPy, not a hippocampus model.

## Task and fixed parameters

- Three sequential tasks A, B, C; ten identity histories per task; six noisy exposures each. At the transition to B and C, A and then B are never shown again. Training uses exactly eight signed 6D events per identity with dt 0.35 and event noise SD 0.018; fast state is reset for every experience.
- Queries have 12D identity keys built from 0.55 task-family + 0.45 item-specific mixture; training cue noise SD 0.035, independent testing SD 0.04, three test repetitions per identity per checkpoint. No target identity or correct state is supplied to the reader at query time.
- Fast autonomous dynamics: eight 2D rotating planes with frequencies 0.2–1.4 rad/time; four fast planes decay with tau=2, four slow planes with tau=35. Contextual input gate 0.4. Physics matrices fixed across seeds.
- Ringdown at times 0,1,2,4,8,16; telescope into difference residues plus core. Use the core for the 8 state dimensions whose survival fraction exceeds .25; use summed differences for 8 fast dimensions. A slow remembered core is inverse-propagated to present; fast residual omits negligible final core. The stored learned output is 16D, never the entire 96D ringdown.
- Online normalized-LMS weights: 12×16 = **192 scalars**. Uniform slow learning rate .12; uniform fast rate .38; selective policy uses slow rate for slow dimensions and fast for fast dimensions.

## Equal-cost comparator arms

1. **sihti_selective**: cue → fast residue / slow core, selectively updated, then decoded.
2. **direct_matched_rates**: cue → full direct state, with the same rates by dimension. Decisive control for whether the residue encoding earns anything.
3. **direct_fast** and **direct_slow**: all direct-state coordinates with a single update rate.
4. **sihti_wrong_band_rates**: the opposite rate allocation, a causal ablation.
5. **fifo_kv**: last six key/state samples, using 6×(12+16)=168 scalars (not exceeding 192).
6. **offline_joint_ridge**: direct cue→state ridge fit once on all tasks together. Equal 192 weights, but privileged retrospective data, so not an online competitor.

All models use the same events and cue perturbations. No hidden rehearsal store or uncharged old-item replay. All online memories start at zero.

## Registered local endpoints and thresholds

After learning C, score: (i) old A late-state NRMSE at t=16; (ii) new C current-state NRMSE; (iii) old A against the direct matched-rate model. NRMSE uses RMS(target) as denominator, so a zero output scores 1.0.

For a **go**, selective residue memory must improve old A late NRMSE over direct_fast by at least 0.05 absolute; be within +0.05 of direct_fast for new C current NRMSE; and improve by at least 0.01 against direct_matched_rates on old A. At least 6 of 8 seeds should show the primary old advantage. Otherwise **no selective-residue advantage**.

Eight fixed seeds 401–408; save all seedwise results in the output generated by `python consolidation_benchmark.py`. Secondary checks: all post-task losses; old-task drift from after A to after C; wrong-rate band ablation; FIFO; offline oracle; Sihti telescope identity and compression/transport error.

## Interpretation limits

Different update timescales can improve old-memory retention without Sihti adding information. A direct per-dimension memory can always exploit known slow modes. Scoring after C with A NRMSE near 1.0 is *not* useful old memory even if another model scores worse. A positive result against only direct_fast would show a learning-rate tradeoff, not a unique residue mechanism or a cure for catastrophic forgetting.
