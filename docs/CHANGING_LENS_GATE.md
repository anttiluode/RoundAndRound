# Gate 5 — The Changing Lens: a living present grazed by several old loops

Date: 29 October 2026. **Exploratory synthetic instrument**, not a preregistered neuroscience or human-personality experiment. An initial non-autonomous version was evaluated on development seeds 901–908 and replication seeds 1001–1008. After inspecting those results, autonomous-time advancement was added to the ongoing present; both splits were rerun. The final 1001–1008 split is therefore **replication, not blind independent confirmation**. The foreign-world policy-transfer check is likewise post hoc exploratory.

## Question

Can remembered *dynamics* influence a continuously evolving present without first wiping the present and restoring an old state? Can an agent learn its memory-access procedure from feedback, and do changes in that learned procedure have effects separable from changes in the memory bank?

This is deliberately narrower than conscious self, human personality, autobiographical memory or biological apical loops.

## Stored memories and partial cues

We reuse Gate 4's `active_reentry_benchmark.learn` to learn three separate 8×8 operators from trajectories of three hidden teacher regimes, with noisy observation. Their context centers are identical. The identity is not presented to retrieval. Slow learned operators are then frozen for all Gate 5 training and test queries.

A new memory cue is a fragment of the response to a current trigger `x`:

```
y_j = v_j @ (M_true @ x) + Gaussian_noise
```

The policy chooses which of six fixed orthonormal measurement axes `v_j` to inspect (or STOP). The entire cue is generated by the evaluation environment, but the policy only receives scalars for the axes it actually selected. Its predictions for each candidate memory come from the stored operators and are updated by a Gaussian Bayesian likelihood, without the true identity.

`x` is an explicit mixture of the continuing present and a common new event:

```
trigger = unit(0.70 * external + 0.30 * unit(present))
```

The environment reveals the correct teacher *after a training episode ends*, solely to compute a reinforcement-learning reward. It is never given to the policy while selecting sensors or to the frozen slow memory.

## The present is not reset

For the present state `z`, the base continuous transition uses a damped rotation `F` and a small new external input, while memories only perturb it:

```
base_next = 0.95 * R @ z + 0.18 * unit(external)
graze     = 0.13 * Σ_i p_i * (M_i - base_operator) @ z
z_next    = base_next + clip_norm(graze, 0.15 * norm(base_next))
```

An explicit autonomous clock advances each present by an independently sampled gap of 0.1–1.0 time units per episode, rotating and decaying the state **without input**, then the next event and retrieved mixture graze it. Each evaluation agent carries one state through **350 successive** episodes. It never restores a saved full state; the maximum memory-induced perturbation per update is capped at 15% of the no-memory next-state norm. `rho=0` eliminates all memory effects on the present and is tested.

## How the policy learns

The policy receives: its probability distribution over remembered operators, predicted responses for the six candidate sensors, which sensors were already read, and the current position in the allowed three-observation budget. A **10-feature shared linear action score + seven action biases + reward baseline** (18 scalar variables) is updated by episodic REINFORCE; this is a small *learned* controller, not Gate 4's analytic eigenvector action oracle.

After the decision, the environment discloses the correct memory source for reward only:

```
reward = log posterior(correct_source) - probe_cost * observations_used
```

Two matched agents share the same learned operators and environment random stream but have different explicitly **engineered training costs**: 0.02 for `discover`, 0.70 for `economical`. Their persistent memory matrices do not change in query learning. These differences in objectives are an experimental intervention, not spontaneous formation of human personality.

Both policies train for 2,600 separate query episodes on the corresponding world's stored memories and receive 350 held-out query episodes. Development worlds 901–908; replication worlds 1001–1008 (reused after the autonomous-time correction).

## Comparators and interventions

- **No cue measurements:** uniform prior, but the same passive mixture of stored operators can still graze the ongoing present.
- **First available axes:** three fixed orthogonal measurements, no training.
- **Best discrete Bayesian variance:** recompute the best of six measurement axes under current posterior, three observations. Strong established analytic baseline; unlike learned policies, has no trained action weights.
- **Swap learned query policies while keeping memory and initial present fixed.** Verifies retrieval *procedure* and memory *content* can be manipulated separately. This is an expected code-level intervention, not a magical new emergent ability.
- **Swap the memory bank with unrelated learned operators while keeping the same trained policy and true environment.** Tests whether actual memory content matters; expected to damage predictions.
- **Post hoc transfer:** freeze policy, change to a novel memory bank and matching novel teacher world, and test without policy retraining. Exploratory, not a preregistered transfer gate.

We count 18 scalars per learned policy **in addition to the same operator-bank memory**, although the strongest analytic baseline is not a trained network. The different methods have different numbers of observations (0–3) and therefore different sensing cost. They do not have matched *wall-clock compute*.

## Metrics and interpretation

1. Memory-source identification accuracy; chance is 1/3.
2. Mean observed scalar cues per query.
3. Reduction of *squared error in present-state consequences* versus an otherwise identical baseline with no memory graze. The target is the unknown true-operator graze. A uniform posterior can already show positive gain; do not conflate the entire gain with learned-policy benefit.
4. The learned policy versus the analytic best-discrete attention control.
5. Invariance of frozen memory weights under reading, no reset of live present, bounded graze and policy swapping.

## Findings and decisions

See [full results](../results/CHANGING_LENS_RESULTS.md), including development and independent confirmation and the complete seed-level JSON.

- **YES, mechanism:** two differently rewarded query learners develop distinct consistent *probe-frequency* habits with the same memory bank; swapping policies swaps that habit. Current-state feedback is nonzero and bounded; memory substitution affects prediction.
- **NO, performance edge:** the inquisitive learned policy is still below the strong Bayesian variance attention control on held-out identification. Both trained policies often collapse to extreme three-observation versus stop-immediately strategies. No sophisticated conditional style has emerged.
- **NOT TESTED:** long-lived self-modifying autobiographical memories, natural biological apical/hippocampal dynamics, safe reconsolidation from trustworthy evidence, transfer to novel nonlinear mechanisms, stable human-like personality, or consciousness.

## Run

```
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python changing_lens_benchmark.py --output results/changing_lens_development.json
python changing_lens_benchmark.py --confirm --output results/changing_lens_confirm.json
```

The experiment uses only NumPy and should run on a normal CPU. The JSON output records every seed, each policy's first sample of actions, confirmation metrics, swap effects and ongoing-state summaries.
